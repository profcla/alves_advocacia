# 🚀 Guia de Hospedagem: Alves Advocacia

Este pacote contém a versão final e otimizada (V8.1) do portal da Alves Advocacia.

## 📁 Estrutura do Pacote
- **index.html**: Website Principal.
- **landing.html**: Landing Page alternativa.
- **simulador.html**: Simulador de Reforma Tributária.
- **admin.html**: Painel de Configuração da IA.
- **app.js**: Motor do Simulador.
- **tax-ai.js**: Robô OpenAI + Chat Integrado.
- **style.css / landing.css**: Identidade Visual Digital.
- **logo_alves.png**: Logotipo oficial.

## 🚀 Como fazer o Upload
1. **Servidor:** Suba todos os arquivos para a pasta principal do seu servidor (ex: `/public_html`).
2. **Acesso Admin:** Acesse `seudominio.com.br/admin.html`.
3. **Ativação:** 
   - Senha: `alves2026`
   - Insira sua **OpenAI API Key** para habilitar o robô.
